## 🌑 THE VOID BECKONS

**BEENHOLLOW** is a peer-to-peer, real-time message and file-sharing interface designed for the abyss. Send your data out into the ether with no intermediaries. Drop files into the void, and let those who hold the key pull them out. 

Built with modern web technologies, it leverages pure P2P connections to ensure your data passes from host to receiver, dissolving entirely once the connection is severed.

---

## ⛓️ FEATURES

- **📡 True P2P Sharing:** Real-time peer-to-peer data transfers using `trystero` and `peerjs`. No central servers storing your files.
- **📦 Ephemeral Data:** What enters the void, stays in the void. Data lives only as long as the connection.
- **⚡ Blazing Fast UI:** Powered by React, Tailwind CSS, and Vite for an uncompromising, fluid experience.
- **📱 Cross-Platform:** Capacitor integration means the void goes with you, whether on desktop or mobile.
- **🕶️ Dark Aesthetic:** A sleek, minimal UI designed for those who prefer the shadows.

## 💀 SUMMONING THE PROJECT

To materialize BEENHOLLOW on your local machine, follow these steps:

### Prerequisites
- Node.js (v18+)
- npm or pnpm

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/your-username/beenhollow.git

# 2. Enter the abyss
cd beenhollow

# 3. Install dependencies
npm install

# 4. Ignite the development server
npm run dev
```

### Build for Production
To package the void for deployment:
```bash
npm run build
```

## 🦇 ARCHITECTURE NOTES

BEENHOLLOW utilizes `trystero` multi-protocol magic (MQTT, Nostr, Torrent) alongside `peerjs` to guarantee connection stability across different network conditions. It dynamically manages file chunking and message passing directly between clients in the browser.
